# 截图答题

适用于 Windows 10/11。在任意应用内按下设定的快捷键，即可截取整个桌面（包括所有显示器），由 DeepSeek 读题并按需联网搜索。独立窗口只显示最终答案，多道题按题号排列。

## 运行

双击发布目录中的 `截图答题-托盘版.exe` 即可启动。同目录下的 `apikey.txt` 可放一行 DeepSeek API 密钥，程序会自动导入，并保存在当前 Windows 账户的凭据管理器中。导入后即使移走 TXT，下次启动也会使用已保存的密钥。要换密钥，更新 TXT 并重新启动即可。

首次启动时若无文件和已保存的密钥，程序会弹窗输入并记住密钥。环境变量 `DEEPSEEK_API_KEY` 优先于文件和已保存的凭据，仅用于本次进程。需要清除记录时，可在 Windows 凭据管理器的“Windows 凭据”中移除普通凭据 `ScreenAnswer/DeepSeek`，并移走同目录的 TXT。

如需从源码运行，可用 Python 3.10+ 在项目目录执行以下命令。

```powershell
python -m pip install -r requirements.txt
python app.py
```

截图在内存中处理，触发后发送至 DeepSeek 官方接口。点击最小化后，主窗口从任务栏收起，程序在通知区域继续运行。截图、收到答案或请求失败时均在后台更新。单击通知区域的“截图答题”图标可恢复主窗口；图标可能位于时钟旁的折叠菜单中。右键图标选择“退出”，或关闭主窗口，即可结束程序。

## 手机接收

1. 将手机和电脑连到同一个可信局域网。电脑也可以用网线连接同一路由器。
2. 在电脑端点击“手机接收”，每部手机都可扫描同一个二维码，在浏览器中打开。手机可随时加入，地址由路由器自动分配。
3. 在电脑上点“完成”，回到题目并使用快捷键。手机页面在前台每秒检查一次，显示最新一次答题的状态和最终答案。恢复到前台时会重新同步。
4. 要结束接收，在电脑上再次点击“手机接收”，选择“停止共享”。下次开启时重新扫码。

手机获得的是只读临时链接，持有链接且能连接到该电脑的人可查看本次共享的答案。若扫码后无法打开，请检查手机是否使用 Wi-Fi、两台设备能否互访，以及 Windows 防火墙是否允许本程序在当前网络接收入站连接。电脑有多块网卡时，可在配对窗口选择与手机同网段的地址后重新扫码。

分发给客户时只需提供托盘版 EXE，客户使用自己的 DeepSeek 密钥。首次开启共享时，在 Windows 的网络访问提示中允许此程序访问客户当前使用的可信网络。如果曾拒绝，可在配对窗口点击“Windows 放行设置”，在系统界面中选择“更改设置”，允许当前路径的托盘版通过对应网络配置文件。需要精细配置时，管理员可限定此程序的入站 TCP 43821、远端“本地子网”和客户实际使用的网卡。程序只在开启共享时监听选定的网卡地址，停止共享即关闭端口并使本次二维码失效。

## 快捷键

默认组合为 **Ctrl+Shift+F8**。点击主窗口的“快捷键设置”，选择主键并勾选组合键，或直接选择鼠标中键、侧键 1、侧键 2。点击“保存”后立即生效，下次双击启动时会沿用。若组合键已被占用，可重新选择。

也可用 `--hotkey` 在本次启动时指定绑定，例如以下任一命令。

```powershell
python app.py --hotkey Ctrl+Alt+Q
python app.py --hotkey F8
python app.py --hotkey middle
python app.py --hotkey x1
python app.py --hotkey x2
```

键盘支持 Ctrl、Shift、Alt、Win 与字母、数字、F1–F24、Space、Enter、Tab、Insert、Home 或 End 组合。middle 表示按下滚轮，x1、x2 表示两个侧键。程序运行期间，选中的鼠标键由截图功能接管。若鼠标驱动已将侧键映射成键盘组合，请绑定对应组合。

可执行文件接受相同参数，例如 `.\截图答题-托盘版.exe --hotkey x1`。也可单击窗口中的“截图答题”。截图前窗口会收起到托盘，等待答案期间重复触发会被忽略。默认模型为 `deepseek-flash`，可用 `--model` 指定支持图像输入和联网搜索的 DeepSeek 模型。
